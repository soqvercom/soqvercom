# SOQVER

Business facts AI agents can rely on.

- **[SO4AG](https://github.com/soqvercom/so4ag)**: an open format for business facts with their meaning, scope, origin and validity. A reader answers one question: may this fact be used for this task now, and if not, why not? Specification, JSON Schema, conformance suite, validator and readers in JavaScript and Python.
- **[soqver.com](https://soqver.com)**: a service that prepares, confirms and publishes SO4AG sources. The format itself is free and needs no account.
- **MCP server**: `https://soqver.com/mcp` (read-only), listed in the official MCP Registry as `com.soqver/so4ag`.

Specification: https://soqver.com/spec/so4ag/0.1/ · Contact: info@soqver.com
